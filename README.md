## Breakout Game Using Pygame

A classic arcade-style Breakout game built with Pygame, featuring unbreakable blocks, timer system, and particle effects.

Features

- Classic brick-breaking gameplay
- Unbreakable blocks (require 2 hits)
- 60-second time limit with progress bar
- Particle effects when bricks break
- 3 lives system
- Score tracking (breakable: 10pts, unbreakable: 20pts)
- Pause functionality
- Multiple win conditions

##  Controls

A - Left
D - Right
Esc - Quit
SPACE - Pause
R - Restart the game
